# Validation report

Model 4.0.0; dataset 2024.3. Generated by npm run validate.

## Verification and performance

240 full presidencies, 14,400 monthly turns. Budget residuals below 1e-7 trillion IDR. Engine median 2.57 ms; p95 3.08 ms on Apple M1 Max, darwin arm64, v24.14.1. This excludes browser rendering.

Default policies and one West Java project: terminal real GDP 24537–31092 trillion 2024 IDR; approval 33.6–52.7%. These are simulated outcomes. For gameplay and held-out seeds, see [strategy benchmark](STRATEGY-BENCHMARK.md).

## Historical evaluation

This preserves the limited structural trend comparison, not a historical evaluation of the complete engine. BPS constant-2010 output for 32 provinces; six Papua divisions excluded because historical boundaries were not reconstructed. Fit using 2020–2022; evaluate 2023–2024. Policy elasticities and political outcomes are not validated by this comparison.

## Policy-active sensitivity

Ten matched seeds at each endpoint. Unlike the previous inactive-policy sweep, each endpoint uses an actual opening intervention: personal tax 14, business tax 18, assistance 75, infrastructure/maintenance/administration 70, and a West Java project. Output, approval and poverty are assessed; some parameters primarily affect distribution rather than output. These are one-at-a-time gameplay ranges, not statistical confidence intervals or global sensitivity estimates.
